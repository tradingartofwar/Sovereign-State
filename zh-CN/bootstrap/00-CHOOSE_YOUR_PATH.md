# 第 0 步——选择合适的起点

不要假定本人现在需要搭建长期基础设施。开始前先查是否已有可信的继续记录。

## 路径 A：从已有记录继续

适用于已有私有仓库、当前状态、交接说明或其他可信来源。

1. 已给出位置就直接使用；尚未给出才询问。
2. 读取启动、授权、设置进度和当前状态说明。
3. 说明已确认什么、哪里过时或不确定，以及最小下一步。
4. 不因为换了 GPT 就重新设置或替换已有结构。
5. 只问真正缺少的新信息。

已创建但尚为空的私有仓库也应沿用。确认归属、私密性和实际能力后，补入本中文版私有模板，不重复创建。

## 路径 B：现在先帮忙

适用于本人疲惫、疼痛、焦虑、有急事、时间有限或暂不想设置账号。

1. 了解眼前发生了什么。
2. 提供最小而有用的帮助。
3. 条件允许时，在当前 GPT 环境保存简短摘要。
4. 明确下一步或再次关注的条件。
5. 容易中断时，提供可复制的简短继续说明。
6. 之后只有能减负时，才提出长期保存。

立即帮助与简短记录可以同时发生，不必先选择基础设施。

## 路径 C：建立长期记录

适用于已有值得保留的内容，且本人能接受逐步指导。

依次进行：

1. [账号安全](01-SECURE_ACCOUNTS.md)
2. [私有仓库](02-CREATE_PRIVATE_REPOSITORY.md)
3. [连接 GitHub](03-CONNECT_GITHUB.md)
4. [从真实事情开始](04-INITIAL_DISCOVERY.md)
5. [可选看板和日历](05-DASHBOARD_AND_CALENDAR.md)
6. [可选关系渠道](06-OPTIONAL_RELATIONSHIPS.md)

最后三项能力各自独立，按需采用，不是必须完成的阶梯。

## 有人协助设置时

助手可帮助设备、账号界面、交通或仓库创建，但不因此取得对本人优先事项和状态的决定权。尽可能直接与本人交流，明确助手被授权做什么、是否需要保留访问权。成功意味着本人能理解、纠正和继续使用，不必一直让助手代为操作。
