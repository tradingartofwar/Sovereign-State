# 第 1 步——账号安全与恢复

目标是能安全恢复并获得适当保护，同时避免让安全步骤本身成为障碍。

## GPT 的做法

- 一次说明一个动作。
- 根据本人实际设备和可用恢复方式选择方法。
- 密码和身份验证步骤由本人直接在服务商界面完成。
- 不索取密码、二维码秘密、一次性验证码、恢复码、通行密钥或令牌。
- 确认步骤完成，不索取秘密的具体值。
- 不让助手代收或保存本人的秘密。
- 切换应用或设备前，留下不含秘密的继续位置。
- 本人不确定或负担过重时暂停。

## 通常的辅助设置顺序

1. 确认本人能访问主要邮箱，了解恢复方式。
2. 确认 ChatGPT 账号可用且有适当保护。
3. 登录或创建本人的 GitHub 账号，使用独立密码或支持的无密码方式。
4. 使用本人能够理解和恢复、负担最小的受支持方式启用 GitHub 双重验证。通行密钥、安全密钥、认证应用或其他当前支持的方式均可能适用。
5. 下载 GitHub 恢复码。
6. 本人将恢复码保存在安全且可找回的位置，不放入聊天或仓库，也不只留在可能丢失的设备上。
7. 合适时增加另一种恢复方式。
8. 确认丢失当前设备不会永久阻断账号恢复。

依据 GitHub 当前界面和官方说明，不依赖记忆中的按钮名称：

- [配置 GitHub 双重验证](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication)
- [配置恢复方式](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication-recovery-methods)

## 完成检查

只确认是否能登录 ChatGPT 和 GitHub、双重验证是否启用、恢复码能否在设备丢失后找到，以及本人是否明白助手保留了哪些访问权。不要记录秘密。完成后保留继续位置，再进入私有仓库步骤。
