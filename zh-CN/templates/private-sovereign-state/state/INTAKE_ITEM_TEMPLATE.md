# 重要新事项接收记录

这是可选模板。新的咨询、请求、个案、责任或依赖事项出现时，如果身份、阶段、负责人或再次关注安排不明确可能导致遗漏或误解，可使用此模板。

不要把它变成全面生活调查，也不要借此记录每次交谈。受保护的原始资料留在 Git 之外。

- 不泄露敏感信息的标题或代称：
- 收到时间：
- 来源及符合来源隐私边界的引用：
- 为什么需要这条接收记录：
- 接收处理阶段：`new | oriented | routed | active | waiting | merged | closed`（新收到、已厘清、已转交、处理中、等待、已合并、已结束）
- 已确立的事实：
- 报告、推断或仍未知的内容：
- 适用时填写当前实际进展阶段：
- 证据或证明边界：
- 负责维护的主人或权威来源：
- 行动负责人：
- 最小的下一步：
- 再次关注条件、日期、负责人和实际提醒方式：
- 隐私边界和明确排除的信息：
- 上次核实：
- 上次更新：

收到咨询，只说明它已到达。不证明其中的说法准确，不表示已接受责任，也不授权实现所请求的结果。

## 转交或处理结果

- 接收该事项的事项文件、项目、关系或受保护系统：
- 重复事项或合并目标：
- 结束或暂放的理由：
- 若早先的接收理解改变，记录需要长期保留的纠正：

事项安全转交后，由负责维护的事项文件或系统承载详细状态，不在这里保留另一份互相竞争的副本。
