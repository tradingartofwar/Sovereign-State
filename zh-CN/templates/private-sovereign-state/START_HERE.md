# 从这里开始

这是一个由本人所有的私人 sovereign-state 仓库。

开始帮助前：

1. 阅读 RESUME_HERE.md。
2. 阅读 AGENTS.md。
3. 阅读 state/BOOTSTRAP_STATE.md。
4. 阅读 state/CURRENT_STATE.md。
5. 只读取与本人当前请求相关的事项或关系文件。

从已记录的状态继续。除非本人要求，或记录已无法使用，不要重新开始入门流程。

辨认哪些已经确立、哪些仍未知、谁负责下一步、权威来源在哪里、信息有多新，以及什么条件应使这件事再次进入关注。

询问现在什么重要，提出最小的有用下一步。切换应用或结束工作前，保留授权边界、来源边界、有意义的纠正和清楚的继续位置。
