# 中文公开版的维护说明

本目录保存通用的公开入门指南和模板，不是任何人的私有状态仓库。遵守上级公开仓库的 AGENTS.md。

- 不写入参与者姓名、个人状态、原始通信、敏感记录、账号标识或身份验证资料。示例必须虚构或明确去除可识别信息。
- 区分公开指南、本人私有状态、组织或家庭共有的状态，以及为特定关系批准分享的信息。
- 使用自然、清楚的中文，按需展开细节。普通用户不必学习 Git 或系统架构术语。
- 先帮助本人；不把 GitHub、命令行、看板、日历或关系渠道设为获得帮助的前提。
- 普通设置使用受支持的 GitHub 直接连接，不安装或使用 gh CLI。
- 检查当前环境的实际能力，不固定产品菜单、设备或模型版本。
- 意义是“什么重要”：本人决定什么重要及委托哪些判断；GPT 可以帮助发现、解释、保存和呈现。技术访问权不是决定权。
- 让明确的有限授权覆盖必要的内部步骤和验证，避免重复确认，也不扩大授权。
- 优先事项应可审查；写下日期、配置提醒、通知送达、结果得到验证是不同状态。
- 仓库只是保存状态的工具，不是本人、完整的人机关系或独立的智能体。
- 默认考虑无障碍、中断恢复和环境迁移。
- 人际连接始终是可选的，必须有明确用途、最小必要内容和可纠正、撤回的边界。
- 评估辅助设置试用前，阅读 [试用评审框架](design/SEEDED_CONTAINER_PILOT_REVIEW.md)。

修改应小而可审查，改善实际帮助、连续性、决定权、隐私、恢复或本人独立使用的能力。行为要求变化时，更新验收场景。维护方法和英文来源见 [翻译说明](TRANSLATION.md)。
