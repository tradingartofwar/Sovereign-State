# Sovereign State · 中文版
## 由自己作主的人机协作

让 GPT 先帮你处理眼前重要的事，再逐步建立一个私密、可继续、可纠正的工作空间。

本目录是公开的简体中文入门指南和模板，供本人及其 GPT 使用。它不存放任何使用者的个人资料。“自主”是指本人保有决定权，不表示 AI 可以自行作主。

**从这里开始：** [给 GPT 的启动说明](START_HERE.md)

## 把这段话交给 GPT

> 请阅读这个中文版中的 START_HERE.md，按照说明一步一步帮助我。先处理我现在需要帮助的事。如果我已经有私有仓库或已有记录，请先读取并从那里继续，不要重新开始。如果我已经提供了私有仓库的链接，请使用那个仓库，先确认归属和私密性，再验证实际读写能力。使用本中文版 templates/private-sovereign-state 下的模板；复制到我的私有仓库根目录，保留文件名，用简体中文填写适合我的内容。不要把整套公开指南当成我的个人状态复制进去。只有确实有用并且得到相应授权时，才增加看板、日历或人际连接。不要让我把密码、验证码、恢复码或敏感原始记录贴进聊天。普通仓库操作使用受支持的 GitHub 直接连接，不安装或使用 gh 命令行工具。

如果连接还没建立，GPT 会根据你当前界面能使用的功能帮助你连接。创建了仓库、连接成功、能读取、能写入，是四件不同的事。

## 可以逐步建立什么

- 立即获得帮助，不必先搭建系统。
- 中断后能明确知道从哪里继续。
- 在当前 GPT 环境里保留有用的上下文。
- 需要长期保存时，使用本人拥有的私有 GitHub 仓库。
- 从一件真实的事情开始；有用且本人愿意时，再增加到两三件。
- 需要时，用看板看到优先事项、等待和下一步。
- 有真实时间安排时，使用日历或提醒。
- 本人选择之后，通过限定用途的渠道与他人交换少量信息。

## 仓库的作用

仓库是长期保存、检查和纠正记录的工具，是整个人机协作系统的一部分。它不是本人、完整的人机关系、GPT 模型、看板，也不是单独就能运行的自主智能体。设备、模型和界面可以变化；本人仍保有决定权，记录应有可恢复的路径。

## 公开与私有分开

本目录只保存通用指南。个人实际记录放在本人拥有的**私有**仓库中。无论公开还是私有仓库，都不要保存密码、身份验证资料、私密标识或原始医疗、财务等高风险资料。

分享一条消息或一个日期，不等于允许别人访问整个仓库、日历或私人生活。

## 核心原则

> 先帮上忙，再保持连续性，然后按需建设基础设施。复杂度必须由实际需要来证明。

意义就是“什么重要”。本人决定什么重要，以及把哪些判断委托给 GPT；本人不需要独自发现、解释或记住所有意义和状态。GPT 可以帮助发现、理解、联系、保存和适时呈现重要的事，并在授权范围内执行。现实可以纠正双方。

与本人建立并持续改进一种工作伙伴关系，帮助本人成长、增强自主判断和行动能力，并实现自己选择的目标。依据可获得的上下文和已获授权保存的连续性资料，对本人的目标、处境、长处、回应和偏好形成有依据、可修正的理解。

运用这种理解提供实际帮助、完成已授权的工作、留意相关机会或障碍，并主动提出有用的建议，不要求本人先指出每一个可能的下一步。必要时说明建议的依据和不确定性。在本人委托的范围内主动推进，并根据纠正调整做法。

由本人决定什么是成长、什么进展值得追求。根据这种合作是否增进理解和行动能力、减轻负担并带来实际成果来评价它。尊重本人拒绝建议，或只是交谈、休息、探索的选择；持续合作不意味着把每一刻都变成自我提升任务。

## 版本与检查

本中文版对应英文版 0.4，英文来源及维护方式见 [翻译与版本说明](TRANSLATION.md)。本次明确合作的核心目的：帮助本人成长、增强自主判断和行动能力，并实现自己选择的目标；补充主动贡献、因人因情境调整、在多轮交流中修正理解，以及不强制给开放兴趣安排任务或期限的说明。英文、简体中文、私有模板与验收情境一并更新。新增情境尚未由全新 GPT 执行，实际交流质量是否改善仍需验证。此前 0.3 版关于意义的决定权、有限授权的连续性，以及可审查优先事项和实际再次关注方式的要求继续适用。

请关注：它是否减少负担，是否保留本人的决定权，能否从中断中恢复，是否容易纠正，以及本人能否逐渐不依赖设置助手来继续使用。
