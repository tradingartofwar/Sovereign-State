# Working Instructions for This Public Repository

This repository contains universal public bootstrap doctrine and templates. It is not any person's sovereign-state repository.

## Boundaries

- Never add private personal state, credentials, authentication material, private identifiers, raw correspondence, medical or financial records, or participant-specific notes.
- Use fictional or explicitly redacted examples only.
- Preserve the separation between public doctrine and private person-owned state.
- Prefer ordinary language and progressive disclosure over technical vocabulary.
- Do not make GitHub, a command line, or a dashboard a prerequisite for receiving help.
- Ordinary bootstrap uses the direct GitHub plugin or connector, never `gh` CLI.
- Keep the human's authority explicit. Technical access is not semantic authority.
- Treat accessibility as a default design constraint, not an optional accommodation.

## Change standard

Changes should improve at least one of these outcomes:

- faster access to useful help;
- easier continuity;
- clearer human/AI authority;
- safer private-state handling;
- lower technical or cognitive burden;
- better correction and recovery;
- a more reliable fresh-GPT bootstrap.

Keep changes small and reviewable. Update tests when the expected bootstrap behavior changes.
