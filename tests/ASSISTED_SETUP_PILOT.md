# Assisted Setup Pilot

Use this test with a real participant and a trusted helper. Do not record the participant's private details in this public repository.

## Observe

- Where did the participant hesitate?
- Which words required explanation?
- Which screen or permission was confusing?
- Did the helper begin making choices that belonged to the participant?
- Did GPT ask too many questions at once?
- Could the participant explain what the private repository was for?
- Could the participant resume after an interruption?
- Did the first three trajectories feel meaningful rather than imposed?
- Was the dashboard offer obviously useful when it appeared?
- Did the calendar preserve appointments, deadlines, plans, reviews, routines, and possibilities accurately?

## Record only public design findings

After the pilot, add only generalized, non-identifying findings to a review or issue. Participant-specific state remains in the participant's private repository or other appropriate source system.

## Passing outcome

The participant leaves with secure recovery, a private person-owned state layer, three useful living trajectories, a clear resume path, and less cognitive burden than they began with.
