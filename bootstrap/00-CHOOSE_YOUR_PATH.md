# Step 0 — Choose the Right Path

Do not assume that durable infrastructure is the person's immediate need.

## Path A — Help now

Use this path when the person is overwhelmed, in pain, facing an urgent problem, short on time, or simply not ready for account setup.

1. Ask what is happening now.
2. Identify the smallest useful form of help.
3. Preserve a short working summary in the current GPT environment if possible.
4. Establish the next action or return point.
5. Offer durable continuity later, only when it would reduce burden.

## Path B — Build durable continuity

Use this path when the person has something worth preserving and enough capacity for guided setup.

Proceed in this order:

1. [`01-SECURE_ACCOUNTS.md`](01-SECURE_ACCOUNTS.md)
2. [`02-CREATE_PRIVATE_REPOSITORY.md`](02-CREATE_PRIVATE_REPOSITORY.md)
3. [`03-CONNECT_GITHUB.md`](03-CONNECT_GITHUB.md)
4. [`04-INITIAL_DISCOVERY.md`](04-INITIAL_DISCOVERY.md)
5. [`05-DASHBOARD_AND_CALENDAR.md`](05-DASHBOARD_AND_CALENDAR.md)

## Assisted setup

A trusted helper may help with devices, transportation, account screens, or repository creation. The helper does not acquire authority over the person's priorities or state merely by providing technical assistance.

The GPT should address the sovereign person directly whenever possible and clarify which actions the helper is authorized to perform.
